# Optional Impeccable integration

Impeccable is an optional third-party design capability for frontend work. Its presence is not assumed by the Kit, and it does not replace the Kit's frontend-design guidance or the project's accepted design system.

Use it only when the active Designer or frontend-engineer context can actually access its capability and instructions. Read those instructions before using it and follow their supported workflow for the assigned page. A profile, file, link, or another agent's report alone does not prove that this context loaded it. Do not invoke `npx` or another launcher to probe availability; a launcher may download or bootstrap a runtime. If availability is unknown, a command is not ready, or the capability is missing, unloaded, or inaccessible, use only accessible guidance and continue with the Kit's frontend guidance without blocking the task or claiming successful use.

Keep the requested page and assigned files as the scope. Do not upload project material to an external service without the relevant user authority. Do not copy/vendor upstream implementation content into the Kit. Do not overwrite `frontend-design`, add or replace brand assets, create `PRODUCT.md` or `DESIGN.md`, enable hooks, or bootstrap a runtime unless the user separately asks and approves that bounded change. Existing project design decisions and user instructions remain authoritative.

The Kit does not install Impeccable. Users may review its official [repository and installation guidance](https://github.com/pbakaus/impeccable) separately. A setup reminder is informational only; it does not detect, download, install, or activate the third-party capability.
